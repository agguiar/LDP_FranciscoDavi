Objetivo do projeto

Aplicar técnicas de tratamento e análise de dados para explorar a distribuição de ocorrências por localização, tipo de crime e período, apresentando os resultados em uma aplicação interativa.

Sobre os dados

A base reúne informações simuladas sobre ocorrências, vítimas, prisões, renda média, índice de violência e nível de risco.

Consultar a base original ↗

Análises disponíveis

  • Evolução das ocorrências ao longo do tempo.
  • Comparação dos totais por cidade e tipo de crime.
  • Comparação de indicadores entre regiões.
  • Mapa de calor por crime e período do dia.
  • Relação entre renda média e índice de violência.
  • Tabelas e indicadores atualizados pelos filtros.

Como foi desenvolvido

  • Verificação de valores ausentes e duplicados.
  • Tratamento de datas e organização das variáveis.
  • Agrupamentos, cálculos e análise exploratória.
  • Armazenamento em SQLite com SQLAlchemy.
  • Dashboard com filtros e múltiplas páginas.
  • Publicação no Streamlit Cloud e GitHub Pages.

Tecnologias utilizadas

Python Pandas Matplotlib Seaborn Streamlit SQLAlchemy SQLite GitHub

Conclusão

O projeto integrou tratamento, armazenamento, análise e visualização de dados. O dashboard permite explorar diferentes recortes da base e acompanhar seus indicadores, demonstrando a aplicação das ferramentas estudadas na disciplina.

Limites da análise

Os dados são simulados e têm finalidade acadêmica. Os resultados não representam a criminalidade real das cidades. Os totais não são taxas por população, o índice de violência não é uma porcentagem e correlação não comprova causalidade.
